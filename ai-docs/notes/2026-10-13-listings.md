## Facts learned

- An issue filed with `gh issue create` does not get the issue form's labels, so the intake workflow skips it. The intake also accepts the HTML comment `<!-- external-plugin-submission -->` in the body; adding it and editing the issue reran intake (run 38479931581, passed).
- Intake warns (non-blocking) that `logo` and `skills` are not Agent Plugins 1.0 fields. `logo` stays for Cursor.
- Intake reviewer signals count repo age, stars and watchers; "pricing" was flagged as a homepage heuristic (the README discusses Roblox costs).
- awesome-copilot rejected seven of the owner's other plugins on 2026-10-12, citing "large batch of closely related submissions", "too product-specific" and "style of working". A rejection is final.
- Copilot CLI 1.0.93 warns that direct repo installs are deprecated; only `plugin@marketplace` installs will stay.
- After a release, the awesome-copilot entry needs a PR bumping `version`, `ref`/`sha` in their `plugins/external.json` (once approved). Cursor re-reviews every update.

## DevForum draft (Community Resources)

Written for Roblox developers. Post from the owner's account; the category wants a resource you made, explained, not just linked.

> **Title:** roblox-agent: skills that make Claude Code, Cursor and Copilot better at Roblox (Studio MCP, Rojo, Luau checks, Open Cloud)
>
> AI coding agents can now talk to Studio through its built-in MCP server, but they still guess at a lot: they call `wait()` and `BodyVelocity`, trust whatever a RemoteEvent sends, overwrite your Rojo files from Studio, and say "done" without running anything.
>
> roblox-agent is five free, MIT-licensed skills you add to your agent. They do not replace Roblox's tools; they tell the agent how to use them.
>
> - **Studio:** connect to Studio's MCP server one way (Roblox's plugin or one manual entry, never both), prove the connection, then run a playtest-and-check loop. Covers the known bugs: disconnects, stale reads before `multi_edit`.
> - **Project:** code on disk with Script Sync or Rojo, a toolchain pinned with Rokit, and one writer per script so Studio and the agent don't fight.
> - **Checks:** one command runs every check a repo can run without Studio: rojo build, selene, StyLua, luau-lsp types, Lune tests.
> - **Cloud:** run Luau in a real server through Open Cloud Luau Execution and upload a place, with your own key. Free.
> - **Workflow:** current API rules (deprecated calls, `UpdateAsync` and session locks for DataStores, RemoteEvent validation and rate limits, checking Toolbox inserts for backdoors) and an AGENTS.md for your repo.
>
> Tested live against Studio and a test place on 2026-10-11. Each skill re-checks Roblox's docs on a schedule, so it stays current.
>
> Install (Claude Code): `/plugin marketplace add m4bwav/roblox-agent` then `/plugin install roblox-agent@roblox-agent`. Copilot CLI and Cursor: see the README.
>
> GitHub: https://github.com/m4bwav/roblox-agent · Wiki: https://github.com/m4bwav/roblox-agent/wiki
>
> Feedback and bug reports welcome in the GitHub issues.
